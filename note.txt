------------------------------------- MIGRATIONS FLASK --------------------------------------

1. Installation : 
    pip install Flask-Migrate
2. Initialisation
    migrate = Migrate(app, db)
3. Utilisation :
    flask --app Rohafya db init
4. Après Modification :
    flask --app Rohafya db migrate -m "Ajout des champs au requests"
5. Mettre à jour la base de données :
    flask --app Rohafya db upgrade
